HOW TO RUN: 
Gameplay is started through the single_agent_hanabi.py file. Once this file is ran from the terminal it will play n_episodes games of Hanabi to completion. This contains the runner for the game, as well as the flags that control the parameters of the gameplay (e.g. players, context level, etc...).
